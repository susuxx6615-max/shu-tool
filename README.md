# 排班表

單檔的人員排班工具。用色塊排班，列印出來是一張 A4 橫式月表。

- 自訂班別名稱、顏色、時數
- 點格子或拖曳填班，右鍵清除，數字鍵 1–9 換筆刷
- 自動統計每人天數／時數、每日出勤人數、各班別每日人數
- 點姓名開個人班表卡：月曆檢視、直接排班（與主表同步）、下載 JPG 傳給員工
- 填時薪自動結算應付金額（全域基本時薪，個別員工可另外調整）
- 匯入紙本班表照片對照核銷，沒出席的日子改成休假後時數與金額即時重算
- 「套用上月」整份複製再修改、畫面字級可放大
- 版面已設定 A4 橫式一頁（約 30 人 × 31 天）

## 部署

整個網站只有 `index.html` 一個檔案，沒有相依套件、沒有建置步驟。

1. 把檔案推上 GitHub
2. Settings → Pages → Source 選 **Deploy from a branch**
3. Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 一兩分鐘後開 `https://<帳號>.github.io/<repo 名稱>/`

也可以直接把 `index.html` 存到桌面，用瀏覽器打開，功能完全一樣。

## 資料存在哪裡

存在**每個使用者自己的瀏覽器**裡（localStorage），不會上傳到任何伺服器。

這代表：不同人打開同一個網址，看到的是各自的班表；清除瀏覽資料或換電腦後資料就不見了。工具內「？ → 匯出備份／匯入備份」可以搬移資料。

如果需要多人共用同一份班表，得改成後端儲存，這份檔案不支援。

### 存成本機檔案使用

把 `index.html` 存到自己電腦後，資料可以直接寫回 HTML 檔本身：

- **儲存檔案**（工具列）：Chrome、Edge 第一次會問要存成哪個檔，之後按一下就覆寫同一個檔。Safari、Firefox 不支援直接覆寫，會自動改成下載一份新檔。
- **另存新版 HTML**（？視窗）：每次都另存一份檔名帶日期的完整檔案，可以留著當版本紀錄。

開啟檔案時，會自動比較檔案內建的資料與瀏覽器裡的資料，載入時間較新的那一份。

## 列印

按「列印班表」，在瀏覽器列印對話框把**背景圖形**打開，班別顏色才會印出來。
